# Папка `image`

Сюда нужно загрузить 7 фотографий автошколы (снаружи и внутри), назвав файлы **строго так, как указано ниже** — сайт уже ссылается на эти имена, поэтому переименовывать ничего в коде не понадобится.

| Имя файла | Что на фото |
|---|---|
| `avtoshkola-avtoklass-01-fasad.jpg` | Фасад здания снаружи |
| `avtoshkola-avtoklass-02-vhod.jpg` | Вход в автошколу |
| `avtoshkola-avtoklass-03-klass.jpg` | Учебный класс |
| `avtoshkola-avtoklass-04-komp-klass.jpg` | Компьютерный класс для тестов |
| `avtoshkola-avtoklass-05-koridor.jpg` | Холл / коридор |
| `avtoshkola-avtoklass-06-auditoriya.jpg` | Аудитория для теории |
| `avtoshkola-avtoklass-07-territoriya.jpg` | Территория / двор |

Формат: JPG или JPEG, без пробелов и заглавных букв в имени файла. Желательно, чтобы каждое фото весило не больше 300–500&nbsp;КБ (сожмите на [tinypng.com](https://tinypng.com), если больше) — это влияет на скорость загрузки сайта и на позиции в поиске.

Пока фотографий нет, сайт всё равно откроется нормально: на их месте просто ничего не покажется (плейсхолдера не будет, картинки скрываются автоматически).

Названия файлов не случайны: поисковики (Google, Яндекс) читают и имя файла, и текст `alt` у картинки — это тоже часть SEO, поэтому имена описательные, а не `IMG_1234.jpg`.
