# Сайт автошколы АВТОКЛАСС

Статический сайт-визитка для ТОО «АВТОКЛАСС» (г. Костанай). Один лендинг, без бэкенда — размещается бесплатно и «навсегда» на GitHub Pages.

## Структура файлов

```
index.html          — вся страница
css/style.css        — стили
js/script.js          — мобильное меню + год в футере
image/                — сюда грузите 7 фото (см. image/README.md)
favicon.svg           — иконка вкладки
robots.txt             — для поисковых роботов
sitemap.xml            — карта сайта для Google/Яндекс
.nojekyll               — отключает лишнюю обработку GitHub Pages
```

## Как опубликовать (5 минут)

1. Загрузите все эти файлы и папки в корень репозитория `AVTOCLASS` (сохраняя структуру — `css/`, `js/`, `image/` именно как подпапки).
2. В репозитории откройте **Settings → Pages**.
3. В блоке **Build and deployment → Source** выберите **Deploy from a branch**.
4. Branch: `main`, папка: `/ (root)`. Сохраните.
5. Через 1–2 минуты сайт будет доступен по адресу:
   `https://avtoclasskost63-creator.github.io/AVTOCLASS/`

Если в итоге адрес репозитория или юзернейм на GitHub будут другими — замените адрес `https://avtoclasskost63-creator.github.io/AVTOCLASS/` во всех файлах (`index.html`, `robots.txt`, `sitemap.xml`) на реальный: там он используется в `canonical`, `og:url`, `og:image`, structured data и т. д. Проще всего — через «Найти и заменить» в редакторе.

## Фотографии

Смотрите `image/README.md` — там точный список из 7 имён файлов, под которые уже настроена страница. Просто положите фото с такими именами — ничего больше делать не нужно.

## Что можно поправить руками

- **Телефоны / часы работы / адрес** — в `index.html` есть несколько мест: секция `#contacts`, шапка сайта (`.phone-link`), футер и блок structured data (`application/ld+json` вверху `<head>`) — при изменении телефона или адреса лучше поправить везде, где он встречается.
- **Тексты** — весь текст на русском лежит прямо в `index.html`, любые формулировки можно смело менять.
- **Цвета** — все цвета собраны в самом начале `css/style.css`, в блоке `:root` (например `--yellow`, `--blue`) — поменяв значение один раз, вы измените цвет везде на сайте.

## Важно про SEO — честно

Сайт полностью технически подготовлен к продвижению:

- семантическая разметка, заголовки, `alt` у всех фото;
- микроразметка `schema.org` (`DrivingSchool`, `FAQPage`) — Google и Яндекс лучше понимают, что это автошкола, её адрес, телефон и часы работы;
- `sitemap.xml`, `robots.txt`, `canonical`, Open Graph;
- адаптивность и лёгкий вес страницы (без лишнего JS).

**Но** сама по себе публикация сайта не гарантирует, что он «сразу вылетит» по общим запросам вроде «автошкола Костанай» — конкуренция по таким запросам обычно высокая, а поисковики ранжируют не только по техническому качеству сайта, но и по возрасту домена, количеству ссылок на сайт и поведенческим факторам. Технически на GitHub Pages сайт живёт по адресу `*.github.io`, у которого меньше «доверия» у поисковиков, чем у отдельного домена — это тоже стоит иметь в виду.

Что реально ускорит попадание в поиск:
1. Добавить сайт в **Google Search Console** и **Яндекс.Вебмастер**, подтвердить права и отправить `sitemap.xml` — так Google/Яндекс узнают о сайте за дни, а не месяцы.
2. Указать ссылку на сайт в карточках компании — **2ГИС, Google Мой бизнес (Google Business Profile), Яндекс Бизнес, 2GIS Kazakhstan** — это и трафик, и ссылки, которые поисковики учитывают.
3. Со временем — пара внешних ссылок на сайт (например, из соцсетей автошколы, если они появятся) заметно помогают.

Ничего из этого не требует денег, просто немного времени отдельно от самой публикации сайта.

## Локально проверить перед загрузкой

Просто откройте `index.html` в браузере двойным кликом — сайт полностью статический, сервер не нужен.
